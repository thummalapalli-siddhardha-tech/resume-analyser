About This Project

AI Career Guide & Resume Builder

This application is designed to support students, graduates, and job seekers with a practical career roadmap and resume improvement workflow.

It combines skill-gap analysis, 30-day planning, resource recommendations, resume evaluation, ATS estimation, and job-search guidance in one modern interface.

The project is built using Python and Flask, with structured JSON datasets for roles, resources, certifications, courses, and job portals.
